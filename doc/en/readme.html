Copy URL

Copy URL is designed for web browsers. It lets you copy URLs to the clipboard without leaving the keyboard, and announces what it copied. It is not designed for browse mode in non-browser applications such as Microsoft Word.

Author: Dennis Long <dennisl@fastmail.com>

Commands

Default shortcutAction
Alt+Control+Windows+CCopy the URL of the current page/document.
Alt+Control+Windows+LCopy the URL of the link at the current browse mode cursor (or navigator object) position - without clicking it.

Usage

Copy page URL: Press Alt+Control+Windows+C while focused in a browse-mode document (e.g. a web page in Firefox, Chrome, or Edge). NVDA will copy the page's URL to the clipboard and speak/braille it.

Copy link URL: Move your browse-mode cursor (or NVDA's navigator object, via Object Navigation) onto a link, then press Alt+Control+Windows+L. NVDA will copy that link's destination URL to the clipboard and speak/braille it, without activating the link.

Settings

Open NVDA menu > Preferences > Settings > Copy URL to find:

  • Gesture configuration - explains how to change either shortcut with NVDA's built-in Input Gestures dialog. Open NVDA menu > Preferences > Input Gestures, find the Copy URL category, then add, change, or remove a gesture for the command you want.
  • Say "URL copied" before speaking the copied page URL - controls the announcement for the Copy Page URL command (Alt+Control+Windows+C).
  • Enable the Copy Link URL command - turns the Copy Link URL command (Alt+Control+Windows+L) on or off entirely. When off, pressing that shortcut just tells you the command is disabled rather than copying anything.
  • Say "Link URL copied" before speaking the copied link URL - controls the announcement for the Copy Link URL command. This is independent of the "Enable" checkbox above - it stays available whether the command is turned on or off.

The default shortcuts are Alt+Control+Windows+C for Copy page URL and Alt+Control+Windows+L for Copy link URL. In Input Gestures, a user can replace either default, add another shortcut, or remove a shortcut. NVDA saves those personal assignments in its standard gesture map, so they continue to work after a restart.

All options are independent of each other. Uncheck a "Say ..." checkbox if you'd rather NVDA just speak that command's copied URL on its own, without a prefix.

Check for Copy URL updates automatically and Check for updates now - see Updates below.

Updates

Copy URL checks for updates. Once a day, a little after NVDA starts, the add-on asks its GitHub repository, github.com/joshknnd1982/copyURL, whether a newer version has been released, and says nothing unless there is one. When there is, a dialog shows what's new in a box you can read line by line, and offers to download and install it. The download must match the release's SHA-256 checksum. Then NVDA asks you to confirm the installation and offers to restart. Your settings are kept.

To check yourself, open the NVDA menu, choose Tools, then Check for add-on updates, and choose Copy URL.... Or press Check for updates now in the add-on's settings: NVDA menu, Preferences, Settings, Copy URL. You can also assign a gesture to Checks for Copy URL updates in NVDA's Input Gestures dialog, under Copy URL. To stop the daily check, clear Check for Copy URL updates automatically in the same settings panel.

UIA Browse Mode Limitation

In Microsoft Edge with Use UI Automation to access Microsoft Edge and other Chromium based browsers enabled in NVDA's Advanced settings, the Copy Link URL command may work, but the Copy Page URL command may be unable to obtain the current page's direct URL and say No URL found. For reliable page-URL copying, use the browser's standard browse-mode accessibility implementation rather than UIA browse mode.

Notes

  • The "copy page URL" command works in any application that exposes a document identifier through NVDA's browse mode (most web browsers).
  • The "copy link URL" command works on links exposed via IAccessible2 (most links in Firefox, Chrome, and Edge). If NVDA can't determine a link's destination, it will say "No link found".
  • If the Copy Link URL command is turned off in settings, pressing its shortcut says "Copy Link URL is disabled in Copy URL settings" instead of copying anything.
  • If no page URL can be found, NVDA will say "No URL found".
  • You can change either shortcut key at any time via NVDA menu > Preferences > Input Gestures > Copy URL.

Privacy and Security

Copy URL collects no information. It reads a URL exposed by NVDA and places that URL on the clipboard only when the user invokes one of its commands.

Once a day, and whenever you ask it to, Copy URL asks GitHub (api.github.com) for the latest release of github.com/joshknnd1982/copyURL. The request carries only the add-on's name and version. It downloads an update only when you choose Download and install. It keeps its update settings, whether to check automatically and when it last checked, in addonUpdates\copyURL.json in NVDA's user configuration folder. Clear Check for Copy URL updates automatically in its settings to stop the daily check.
